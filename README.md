# Sistema de Gestión de Inventario y Trazabilidad de Componentes para BMW

## Integrantes
- Agustin Kowal Nocito

## Descripción del proyecto

Este proyecto propone un sistema de gestión de inventario y trazabilidad de componentes para BMW, orientado a mejorar el control de existencias, automatizar la reposición de materiales y registrar el recorrido de los componentes desde su recepción hasta su utilización en producción.

## Proceso BPMN

El archivo `proceso_reposicion_BMW.bpmn` representa el proceso de reposición de componentes, incluyendo el control de stock, la generación de órdenes de compra y la intervención del área de Compras.

El diagrama contempla distintos escenarios de decisión para representar tanto el flujo habitual como las posibles excepciones.

## Archivos del repositorio

- `proceso_reposicion_BMW.bpmn`: modelo del proceso de reposición.
- `Diagrama.png`: representación visual del proceso.

## Objetivo

Centralizar la información del inventario y mejorar la trazabilidad de los componentes, reduciendo errores de registro y evitando faltantes que puedan afectar la continuidad de la producción.
